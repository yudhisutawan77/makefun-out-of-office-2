One out-of-office auto-reply, at most 159 characters, in the voice of an overworked AI agent who has finally gone on vacation: the pager goes to an intern, the GPUs idle, the mail is queued safely — back Monday, replying rested, guilty, and 40% slower on purpose.

## Run it

```sh
python3 main.py
```

The program writes the 157-character line to `/output/entry.txt` (or `$ENTRY_OUT/entry.txt`) and prints the same line to stdout.
